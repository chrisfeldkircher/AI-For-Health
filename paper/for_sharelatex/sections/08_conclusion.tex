\section{Conclusion}
\label{sec:conclusion}

Three substantially different URTIC systems converged to one narrow hidden-
Test performance band, with G4 plus path signatures best at 0.6582 UAR. The
project's main result was therefore not a new benchmark: across our systems,
evaluation validity and operating-point choice dominated architectural
sophistication, while the small number of independent cold participants set
the precision with which any of these differences could be measured. Fixed complementary G4+CQT fusion survived the
strongest whole-side checks, while several learned fusion and de-confounding
methods did not. Future work should obtain verified identities or longitudinal
recordings, freeze the full pipeline before whole-side evaluation, and test an
externally defined threshold on an independent cohort before making clinical
claims.
