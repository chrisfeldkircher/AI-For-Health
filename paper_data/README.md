# paper_data/

Compact plot-ready CSVs for the URTIC Cold-detection paper. Generated by
`build_paper_data.py` from the experiment outputs under `results/`.

The whole directory is < 200 KB, so it travels cleanly across machines without
copying the multi-GB feature caches (`cache/microsoft_wavlm-large/pooled/`,
`cache/handcrafted/`, etc.). Pull this directory on the Mac and all paper
figures and tables can be plotted from these CSVs alone.

## Column glossary

- `devel_test_uar`: UAR on the canonical `devel_test` partition (SPLIT_SEED=42, StratifiedGroupKFold by k=210 pseudo-speakers from ECAPA-TDNN embeddings). Range [0, 1].
- `recall_C` / `recall_NC`: per-class recall on `devel_test` at the locked `τ` (operating-point threshold trained on `train_threshold` to maximise UAR). Cold rate is ~9.5%, so `recall_C` is the minority-class recall.
- `shadow_seed`: SPLIT_SEED for StratifiedGroupKFold on the devel half. Shadow seeds used: `{1, 2, 3, 5, 11, 17, 23, 31, 53, 99}` (10 splits). `42` is the canonical.
- `canonical_z_sigma`: number of shadow-distribution σ's the canonical UAR sits above the shadow mean. +1.24σ is the K=2 ensemble case (marginal canonical favourability).
- `paired_lift`: per-split difference, then mean and std across the 10 shadow splits. `n_positive` is the count of shadow splits where the method beats its baseline. ≥ 7/10 + `paired_lift_mean ≥ 0.003` is the pre-registered admission rule for promoting a method to canonical headline.
- `sub@1` (in layer audits): subtractive honesty score, `label_gain − speaker_gain` clamped at 0; the load-bearing per-layer score used to init the A2.5 layer-weight softmax.
- `β`: late-fusion mixing weight, `fused = a2.5_logit + β · z_logit_g`. K=1 locked at β=6 (G4); K=2 locked at β=8 (G4 + G5).
- `τ`: logistic threshold on `softmax(z)[1] - softmax(z)[0]` chosen on `train_threshold` to maximise UAR. Operating-point varies seed-to-seed.

## Loading examples (Python, on your Mac)

```python
import pandas as pd
import matplotlib.pyplot as plt

# 1. Cumulative stack (paper Table I)
stack = pd.read_csv("paper_data/cumulative_stack.csv")
print(stack)

# 2. Shadow-distribution box plot
df = pd.read_csv("paper_data/shadow_distributions_long.csv")
df_shadow = df[df.partition == "shadow"]
df_shadow.boxplot(column="devel_test_uar", by="method", rot=45)
plt.axhline(0.71, ls="--", color="red", label="2017 baseline")
plt.show()

# 3. Speaker-smoothing α curve (M19)
sm = pd.read_csv("paper_data/speaker_smoothing_alpha_sweep.csv")
plt.plot(sm.alpha, sm.canonical_devel_test_uar, marker="o")
plt.axhline(0.709, ls="--", label="α=1 lock")
plt.xlabel("smoothing α"); plt.ylabel("canonical devel_test UAR")
plt.legend(); plt.show()

# 4. β-sweep curve
b = pd.read_csv("paper_data/beta_sweep_k2.csv")
plt.errorbar(b.beta, b.uar_devel_test_argmax_mean, yerr=b.uar_devel_test_argmax_std, marker="o")
plt.xscale("symlog", linthresh=0.5)
plt.xlabel("β"); plt.ylabel("UAR (argmax devel_test)")
plt.show()
```

## Regenerating

If new experiments land under `results/`, just re-run:

```bash
python paper_data/build_paper_data.py
```

The script is idempotent and overwrites all 16 CSVs each time. Total runtime
< 1s on a laptop (pure JSON parsing).

## Note on what is **not** here

- **Per-chunk logits and ROC/PR curves**: not exported by default — these would
  be ~1 MB per (method × split) and balloon to ~100 MB for all multi-K variants.
  If you need them on Mac, add an `export_per_chunk_logits.py` step that loads the
  saved per-seed checkpoints and writes a per-chunk score CSV per (seed, split).
  The locked-τ headline numbers in `multi_k_per_split.csv` are sufficient for
  the headline ROC point.
- **Per-utterance attention weights / hidden-state activations**: not relevant
  to any current paper figure.
- **Mixup / SupCon / adversarial training logs** (A5.5 / A6 / A7 negative-control
  experiments): the verdicts are summarised in `methodology_table.csv` rows
  M8–M14; the raw training curves were not load-bearing for any paper figure.
